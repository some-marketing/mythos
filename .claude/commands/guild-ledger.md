> Authority: `system-status` — this mythic name is an alias; state and errors belong to the resolved command.

<objective>
Read the guild ledger: the overall Mythos system status — grimoires (frameworks), patrons (clients), contracts (projects), and guild health.
</objective>

<process>
1. **Grimoires (frameworks):** Count by service category, list each with version and rank.
2. **Patrons (clients):** Count, list with codes and names.
3. **Contracts (projects):** List contracts across all patrons with status.
4. **Guild Health:** Check for missing stat blocks (manifests), broken references, incomplete grimoires.
</process>

<success_criteria>
- All grimoires, patrons, and contracts enumerated
- Guild health issues identified and reported
- Output organized by section
</success_criteria>
