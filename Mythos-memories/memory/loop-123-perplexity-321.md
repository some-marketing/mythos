`123|perplexity|321` is the operator's shorthand for the pattern already embodied by `/el`, `/dl` and `/bp-r`. Operator definition, verbatim (2026-07-29): *"mind 1, 2, 3 then distinct external research then 3, 2 1 review the aversarial review"*.

**Forward leg (1→2→3):** dispatch to three *distinct* minds — distinct family, not three parallel contexts of the same model. Same-model subagents are parallel contexts, not distinct intelligence.

**Middle (perplexity):** distinct *external* research, outside the repo and outside all three minds. Prefer the Pro browser path (`tools/ai-bridge/perplexity-browser.js`); API fallback `tools/ai-bridge/perplexity-api/`. See [[perplexity-query-js-is-broken]].

**Return leg (3→2→1):** fold back in reverse, each mind reviewing the adversarial review that preceded it. The return leg is the part that is easy to skip and is the whole point — it is review *of the review*, not a second opinion on the original artifact.

**Why:** a single adversarial review is one mind's opinion presented as a verdict. The return leg tests whether the critique itself holds. Convergence between minds is not corroboration when they share a stale corpus — this was demonstrated live on 2026-07-29 when two independently dispatched minds both returned obsolete pre-Andromeda Meta ad-density guidance and agreed with each other.

**How to apply:** use when the work is consequence-grade (plans, architecture, security repairs, anything BIG). Do not stop at the forward leg — a one-review pass is a partial run of this pattern, and should be named as such rather than reported as if the loop completed. Findings the producer fixed still need the return leg: a producer never validates its own trial.
