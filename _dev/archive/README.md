# `archive/`

Dated cold storage for finished artifacts, laid out as `{year}-{month}/{surface}/` —
for example `2026-07/analysis/`. Plain gloss: your dated archive directory; every move
into it is logged to `../logs/archive.jsonl` per `../policies/data-handling.md`.

Archived artifacts remain readable for audit but should not appear in default status
surfaces. Nothing here is deleted without explicit operator confirmation.
