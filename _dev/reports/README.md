# `reports/`

Where a session writes what it found or decided, so the next session (or actor) never
has to reconstruct it from memory. Plain-software gloss: this is your reports/output
directory — analysis writeups, structured signal handoffs, and lifecycle event logs.

Subdirectories: `analysis/` (findings and quest-charter drafts), `signals/`
(structured handoffs between actors), `lifecycle/` (hook and event traces). See each
subdirectory's own README.
