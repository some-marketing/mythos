# `reports/analysis/convene-runs/`

Durable records of a convened council session — each subdirectory is one run of
`/conclave`, holding the dispatched prompts, each lobe's response, and the synthesis.
Plain gloss: your multi-model-review transcript directory, one folder per session.

These are evidence artifacts: a claim that "the council reviewed this" should point
here, not to chat memory.
