# `reports/analysis/task-plans/`

Quest charters (task plans) written by `/plan-quest`, awaiting trial (`/trial-quest`)
or execution (`/embark`). Plain gloss: your generated-plan directory — one bounded
charter per task, each with matched grimoire, gates, and risk notes.

A charter here is active until embarked and closed; see `../../../policies/plan-contract.md`
for the structure every charter must expose.
