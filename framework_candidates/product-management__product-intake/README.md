# product-management__product-intake

Iron research candidate synthesized from the BMAD product-intake pattern through the χ evidence loop.

## What it is

A reports/review-only workflow that turns an early product idea into a bounded product brief, evidence ledger, PRFAQ, open-question list, and readiness verdict.

## Candidate boundary

- This is not BMAD Method and does not copy its code, installer, agents, personas, or surrounding architecture.
- The reusable import unit is upstream product definition before implementation planning.
- Initial execution modes are `RUN_ONLY` for contracted report artifacts and `REVIEW_ONLY` for the independent verdict.
- Promotion requires replay evidence, independent review, sanitization, operator feedback, and the normal rank gate.
- The included replay record is a structural preflight only; it is not evidence that the prompt chain has run successfully.

## Start here

- `candidate.json` — current maturity and blockers
- `evidence/` — χ provenance and transfer rationale
- `proposed_framework/` — draft framework
- `replay_cases/neutral-internal-tool/` — bounded replay seed
- `learning/` — feedback and system-signal ledger
